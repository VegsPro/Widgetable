# Widgetable — Besties & Couples

Милое Android-приложение для пар и лучших друзей с совместными виджетами и виртуальными питомцами.

## Возможности

- 🐱 **Совместное выращивание питомцев** (кормить, играть, уровень)
- 😊 **Настроение** — делись эмоциями с друзьями
- 💕 **Счётчик «Скучаю»**
- 👥 **Друзья по коду** (6-значный код)
- 📱 **Виджеты** на домашний экран (Питомец, Настроение, Скучаю)
- 🔐 Firebase Auth + Realtime Database

## Сборка

APK собирается автоматически через GitHub Actions при каждом push в `main`.

1. Открой вкладку **Actions**
2. Дождись зелёной галочки
3. Скачай артефакт `Widgetable-APK`

## Firebase

Приложение использует проект `vix-hub-3caca`.  
`google-services.json` уже включён (package `com.vixhub.ms`).

## Важно

Это **вдохновлённая версия**, а не 1-в-1 клон оригинального Widgetable.  
Основные механики реализованы и работают через Firebase.
